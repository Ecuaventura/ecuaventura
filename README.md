# EcuAventura: El Laberinto Matemático

Videojuego 2D para aprender ecuaciones de primer grado (1.° a 5.° de secundaria).
Cliente: I.E. N° 54037 Micaela Bastidas Puyucahua – Tamburco, Abancay.

## Mundos
1. Mercado – términos semejantes (1.° sec)
2. Terminal de buses – paréntesis (2.° sec)
3. Puerto – paréntesis en ambos lados (3.° sec)
4. Construcción – fracciones y paréntesis (4.° sec)
5. Feria del pueblo – fracción sobre fracción (5.° sec)

25 niveles · 75 retos aleatorios · botón "Ver ejemplo" paso a paso · funciona sin internet.

## Tecnologías
Phaser 3 · Vite · JavaScript · Electron (instalador .exe) · almacenamiento local (sin internet)

## Cómo ejecutarlo
    npm install
    npm run dev
