# Guía rápida de EcuAventura

Cómo jugar en una página. Responsable: **Yenifer Gonzales Quispe** (Documentación).
Manual completo: `docs/4_Manual_de_Usuario_Yenifer_Gonzales.docx`.

## 1. Empezar
1. Abre **EcuAventura** desde el escritorio o el menú Inicio.
2. Pulsa **Nueva partida**, escribe tu nombre y elige tu personaje.
3. Pulsa **Empezar aventura**.

¿Ya jugaste antes? Pulsa **Continuar** y elige tu nombre: el juego sigue donde te quedaste.

## 2. Controles
| Tecla | Acción |
|---|---|
| Flechas o W A S D | Moverse |
| Espacio | Hablar, recoger objetos o entrar |
| Enter | Comprobar la respuesta |
| M | Ver el mapa completo |
| F11 | Pantalla completa |
| Esc | Cerrar paneles |

## 3. Los mundos
| Mundo | Grado | Tema |
|---|---|---|
| 1 · Mercado | 1.° sec | Términos semejantes |
| 2 · Terminal | 2.° sec | Paréntesis |
| 3 · Puerto | 3.° sec | Paréntesis en ambos lados |
| 4 · Construcción | 4.° sec | Fracciones y paréntesis |
| 5 · Feria del pueblo | 5.° sec | Fracción sobre fracción |

- **Mundos 1 y 2:** laberintos. Cada vecino te bloquea el paso hasta que resuelvas su reto.
- **Mundos 3, 4 y 5:** mapa abierto. Busca los objetos que brillan ✨ para desbloquear misiones.

## 4. Resolver un reto
1. Lee la historia y la ecuación (términos con *x* en azul, números en amarillo).
2. Resuélvela en tu cuaderno.
3. Escribe el valor de *x* y pulsa **Comprobar**.

## 5. Ayudas y puntos
| | |
|---|---|
| ✅ Respuesta correcta | +100 puntos |
| 🔥 3 aciertos seguidos | +50 de bono (racha) |
| 📖 **Ver ejemplo** | Ejercicio parecido resuelto paso a paso — **gratis** |
| 💡 **Pista** de Ecu | Ayuda con tu ejercicio — **−50 puntos** |
| ⭐ Estrellas | 1 a 3 por nivel según errores, pistas y tiempo |

## 6. Preguntas frecuentes
- **¿Necesito internet?** No.
- **¿Sale “Ingrese un número válido”?** Escribe solo números (puedes usar coma: 2,5).
- **¿Se repiten los ejercicios?** No, cada vez son distintos.
- **¿Se guarda mi avance?** Sí, automáticamente en la computadora.
